# NeuraNotes

A simple, static concept page for a “second brain” note-taking app. The demo runs entirely in the browser and does not save or send your messages.

## View locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Add `index.html` and this `README.md` to the root of a GitHub repository.
2. On GitHub, open the repository’s **Settings**.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/(root)` folder, then click **Save**.
6. After GitHub Pages finishes deploying, visit the URL shown in the Pages settings.

## About the demo

The chat displays sample replies; it is not connected to an AI service or a notes backend. Messages are only shown in the current page and are not saved.
